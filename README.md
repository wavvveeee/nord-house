# NORD HOUSE — демонстрационный сайт

Статический адаптивный сайт на HTML, CSS и JavaScript.

## Запуск
Откройте `index.html` в браузере. Для локального сервера можно использовать расширение Live Server в VS Code.

## Структура
- `index.html` — разметка и контент
- `styles.css` — оформление и адаптивность
- `script.js` — мобильное меню, год в подвале и демонстрационное поведение формы

## Перед передачей реальному клиенту
1. Заменить название, тексты, фотографии, контакты и регион.
2. Заменить концептуальные проекты реальными работами и убрать соответствующие демо-пометки.
3. Подключить форму к серверу или CRM и протестировать доставку заявок.
4. Добавить настоящую политику конфиденциальности и корректное согласие на обработку персональных данных.
5. Проверить домен, HTTPS, аналитику, SEO и скорость загрузки.
6. Убедиться, что у клиента есть права на все используемые изображения и материалы.

Фотографии загружаются с Unsplash по внешним URL; для коммерческой публикации лучше выбрать и проверить лицензии конкретных изображений либо использовать материалы клиента.

Все названия, проекты и тексты об NORD HOUSE — демонстрационные и не описывают реальную строительную компанию.
